# API v1 Changelog

All notable changes to the AIVO Public API v1 are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## [1.0.0] — 2025-07-01

### Added

- **Learner Progress API** — `GET /public/v1/learners/:learnerId/progress`
  Retrieve per-subject mastery, skill counts, and engagement metrics for a given learner.
- **Session Data API** — `GET /public/v1/learners/:learnerId/sessions`
  Paginated session history with duration, activities completed, and subject breakdown.
- **External Learning Events API** — `POST /public/v1/events/external-learning`
  Submit learning events from third-party platforms (Khan Academy, IXL, etc.) into the AIVO learner model.
- **API Key Authentication** — All public endpoints require a valid API key via the `X-Api-Key` header.
- **Per-Tenant Data Access Controls** — Tenant administrators can enable/disable progress, session, and external event data sharing.
- **Usage Logging** — Every public API call is logged with endpoint, status code, response time, and client IP.
- **Versioning Headers** — All public API responses include `API-Version` and `API-Current-Version` headers.
- **Rate Limiting** — Enforced per API key with configurable per-minute and per-day limits.
